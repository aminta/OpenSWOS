# ai-notes — working memory for AI sessions (convergence project)

Not developer documentation (that is `docs/convergence/`). Short facts, decisions and next steps so
a new session resumes without re-reading the code. Keep each file under ~150 lines; every code fact
carries `path:line @ commit`. Update at the end of every work block.

Files:
- `state.md` — project state, decisions, open questions, next step
- `code-map.md` — where competition logic lives in OpenSWOS (path:line @ 584367a) and the Mod
- `rules.md` — the working rules for this project (who approves what, budget, no-touch areas)
